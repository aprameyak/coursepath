# CoursePath

Real outcomes data for education programs. Track and share employment rates, salaries, and time-to-job.

## Features

- Add education programs (bootcamps, universities, online)
- Report outcomes: employment status, salary, time to first job
- See real statistics: employment rate, median salary
- Crowdsourced data transparency

## Quick Start

```bash
npm install
npm start
```

Open `index.html`. API on port 3003.
